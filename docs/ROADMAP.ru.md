# План проекта

Готово: подготовка данных, анализ, обучение и оценка моделей, интерфейс с ML-прогнозом и публикация сайта v2. Инференс работает в браузере; отдельный FastAPI пока не создан. Следующие возможные этапы — дополнительные временные проверки, новые данные и API. Отчёт открывается через `START.html`.

Перед каждым этапом описываем действия, цель и ожидаемый результат. После — проверку и фактически полученные результаты.

## 1. Подготовка

- Создать структуру, Git и отдельное Python-окружение.
- Зафиксировать задачу и правила оценки в README.
- Добавить проверку исходного CSV без сторонних библиотек.
- Не устанавливать Docker, PyTorch и фронтенд-зависимости заранее.

Готовность: команда `python scripts/inspect_data.py --help` работает; статус Git понятен; объём папки измерен.

## 2. Данные и анализ

- Скачать небольшой архив UCI, проверить условия использования и указать источник.
- Сохранить контрольную сумму и исходные данные без изменений.
- Проверить пропуски, повторения и пропущенные часы; не считать отсутствующую строку нулевым спросом.
- Построить графики спроса по часам, дням недели и погоде.

Готовность: отчёт с наблюдениями и ограничениями. Учитываем, что погодные величины в исходном наборе нормализованы; единицы и преобразования проверяем по документации.

## 3. Первая модель

- Установить минимальные зависимости в отдельное окружение и записать версии.
- Разделить данные по времени целыми днями.
- Реализовать базовый прогноз по среднему спросу для часа недели на обучающей выборке.
- Сравнить Ridge и HistGradientBoostingRegressor на валидации.
- Исключить утечки ответа, обучать преобразования только на train.

Готовность: воспроизводимая команда обучения и таблица измеренных метрик.

## Место на диске

До начала подготовки на C было около 27,9 ГБ свободно. Это снимок состояния, не постоянное значение.
Окружение находится в `.venv` внутри папки проекта на рабочем столе и исключено из Git. На этапе установки используем pip без кеша. Не создаём несколько окружений для одной задачи. Данные и модели не коммитим.
